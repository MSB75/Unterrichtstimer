ⓘ Informationen zur App

🎯 Zweck der App

Der Unterrichtstimer bildet mehrere Phasen einer Unterrichtsstunde auf einer analogen Uhr ab. Die Uhr zeigt gleichzeitig die aktuelle Uhrzeit mit Stunden-, Minuten- und Sekundenzeiger.

⏱️ Timerphasen

Jede Phase besitzt einen Namen und eine Dauer in Minuten. Die Phasen werden als Segmente am Rand der Uhr dargestellt. Während des Ablaufs wird die aktuelle Phase hervorgehoben und die verbleibende Zeit angezeigt.

🖼️ Eigene Bilder

Zu jeder Phase kann ein Bild aus einem lokalen Ordner des Geräts ausgewählt werden. Das Bild wird ausschließlich lokal in der App gespeichert und nicht an einen Server übertragen.

🔔 Tonsignale

Zur Auswahl stehen Schulgong, Digital, Sanft und Stumm. Die Signale werden direkt im Browser erzeugt; es werden keine Audiodateien oder externen Dienste benötigt.

⏳ Startverzögerung

Optional kann vor dem Beginn der ersten Phase eine Startverzögerung in Minuten eingestellt werden.

📚 Gespeicherte Schulstunden

Unterschiedliche Phasenabläufe können unter frei wählbaren Namen wie „Mathe“ oder „Deutsch“ gespeichert und später wieder geladen werden. Dabei werden Phasenname, Reihenfolge, Dauer und zugeordnete Bilder übernommen. Schülernamen und individuelle Unterrichtsziele bleiben unabhängig von der gewählten Stunde erhalten.

🖼️ Schnellbilder

In der Timerkonfiguration können bis zu zwanzig eigene Bilder aus lokalen Ordnern als Schnellwahl hinterlegt werden. Diese Bilder lassen sich anschließend jeder Unterrichtsphase mit einem Fingertipp zuordnen. Zusätzlich kann weiterhin direkt pro Phase ein eigenes Bild gewählt werden.

🚦 Individuelle Unterrichtsziele & Mitarbeit

In der Timerkonfiguration können zu jedem Schüler individuelle Unterrichtsziele angelegt und optional mit eigenen Bildern visualisiert werden. Während jeder Unterrichtsphase wird jedes hinterlegte Ziel über eine Ampel mit Rot, Gelb oder Grün bewertet. Die abschließende Gold-, Silber- und Bronze-Platzierung wird aus den Zielbewertungen der einzelnen Schüler berechnet. Bei gleicher Punktzahl erhalten Schüler dieselbe Platzierung.

💾 Lokale Speicherung

Timerkonfiguration, Startverzögerung, Tonsignal und ausgewählte Bilder werden ausschließlich lokal auf dem Gerät gespeichert. Es werden keine Nutzungsdaten übertragen.

📴 Offline-Nutzung

Nach dem ersten vollständigen Laden speichert ein Service Worker die App-Dateien auf dem Gerät. Danach kann die installierte App ohne Internetverbindung verwendet werden.

☁️ Hosting & Server

Bei einer Bereitstellung über GitHub Pages oder einen anderen Webserver können technisch notwendige Server-Protokolle wie IP-Adresse, Zeitstempel und Browsertyp verarbeitet werden. Die App selbst enthält keine Analyse-, Werbe- oder Trackingdienste.
